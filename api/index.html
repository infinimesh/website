API referencebeta

This is the REST view of the infinimesh API. The same calls exist over gRPC and Connect. The spec is built from infinimesh/proto. It is beta and may change until the v1 API is released. Devices can send state with POST /devices/states and a device token. Get a device token with POST /devices/token (user login is POST /token), then send it as Authorization: Bearer. Download the OpenAPI 2.0 spec.
