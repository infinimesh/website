API referencev1 stable

This is the REST view of the infinimesh API. The same calls exist over gRPC and Connect. The spec is built from infinimesh/proto. The v1 API is stable: see the versioning policy. Log in with POST /v1/token and get a device token with POST /v1/devices/token, then send it as Authorization: Bearer. Devices send their own JSON with POST /v1/ingest (16 KB max, 60 requests a minute) and read desired state with GET /v1/ingest/desired. Addons follow GET /v1/devices/states/stream per account or namespace. Download the OpenAPI 2.0 spec.
